# wallayout

Gallery wall planner: a single-file web app for laying out picture frames on a wall, generating a hang sheet, and projecting the layout onto the wall with a calibrated projector.

Open `index.html` in a browser. No build step or dependencies (the Instrument Sans font loads from Google Fonts, with a system-font fallback). Plans are saved in the browser's localStorage and can be shared as a `GWP1:` code.
